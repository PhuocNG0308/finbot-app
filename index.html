Control Spending

Control Spending is a personal expense tracker used by a single person. It reads bank transaction notification emails from its owner's own Gmail inbox (read-only access), extracts the amount, date and merchant of each transaction, and stores them in a private database so the owner can see monthly spending summaries in a private Discord channel.

The app is not offered to the public and has no other users.
